# Triage labels

The skills speak in terms of five triage roles. In the Tempo Linear project each role is a label of the same name.

| Role              | Label in Linear   | Meaning                                         |
| ----------------- | ----------------- | ----------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Needs evaluating before anyone works on it      |
| `needs-info`      | `needs-info`      | Waiting for more information                    |
| `ready-for-agent` | `ready-for-agent` | Fully specified; an agent can pick it up        |
| `ready-for-human` | `ready-for-human` | Needs a human to implement it                   |
| `wontfix`         | `wontfix`         | Will not be actioned; also set state `Canceled` |

An open issue with none of these labels has not been triaged yet.
