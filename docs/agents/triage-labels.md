# Triage labels

Triage roles are Linear labels of the same name in the Tempo project.

- State: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix` (also set state `Canceled`). An open issue with none of them is untriaged.
- Category: `bug` (something is broken) or `enhancement` (a new feature or an improvement). A triaged issue carries one category and one state.
